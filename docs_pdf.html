1. Executive Overview

EcoCollect is a modern, responsive, circular-economy web application designed for metropolitan smart cities. Electronic waste (e-waste)—including discarded laptops, smartphones, flat-screen televisions, lithium batteries, and cooling appliances—is the world's fastest-growing domestic waste stream. When disposed of improperly in informal landfills, it leaches neurotoxins such as lead, mercury, and cadmium into groundwater, while wasting metric tons of recoverable critical minerals (gold, copper, lithium, and rare-earth elements).

EcoCollect resolves this systemic crisis by connecting citizens directly with certified green-fleet collection agents and licensed recycling hubs through an intuitive digital lifecycle: Request ➔ AI Classification ➔ Smart Assignment ➔ Real-Time Telemetry Tracking ➔ Scale Weigh-in Verification ➔ Two-Way Ratings ➔ Eco Points Rewards.

2. Complete Technology Stack

The frontend has been engineered entirely with pure web standards to ensure zero framework lock-in, lightning-fast rendering, cross-browser compatibility, and seamless hosting on static edge environments like GitHub Pages.

HTML5 & Semantic Structure Markup

Semantic document outline, accessible forms, camera input integration, and responsive viewport optimization.

CSS3 & Custom Design System Styling

Inspired by botanical warm-paper aesthetics (#FAF7F0 base, deep forest green #1E5E3A, sage accents, lavender pill buttons). Uses CSS Grid, Flexbox, and media queries.

Vanilla ES6+ JavaScript Logic Engine

Pure modern modular JavaScript without React, Angular, or Vue. Clean separation between data persistence, UI controllers, and algorithms.

Leaflet.js & OpenStreetMap Mapping & GPS

Interactive cartography, custom SVG pin markers, doorstep draggable picker, polyline route drawing, and simulated live telemetry motion.

Chart.js Visualizations Analytics

Dynamic charts: Monthly intake trend (Area), category composition (Doughnut), request funnel (Bar), fleet performance, and zone distribution.

HTML5 LocalStorage Engine Persistence

Robust client-side database layer with unified CRUD functions (saveData, getData, updateData, deleteData) and realistic seed datasets.

4. Key Algorithms & Technical Innovations

A. Smart Collector Dynamic Assignment Algorithm
When a citizen schedules a collection, the engine runs a multi-factor ranking formula:
CollectorScore = S(Category) + S(Distance) + S(Rating) + S(Workload) + S(Availability)
• Category Stream Match (35 pts): Ensures the collector's fleet vehicle (e.g. E-Cargo Bike vs Heavy EV Truck) supports the hardware.
• Proximity via Haversine Distance (up to 25 pts): Computes exact spherical distance (km) between doorstep coordinates and collector coordinates.
• Rating Score (up to 20 pts): Rewards operators with proven high satisfaction scores.
• Workload Load Balancing (up to 15 pts): Prioritizes available operators with fewer pending jobs to prevent urban bottlenecks.
B. Real-Time Telemetry & Route Simulation
A visual 7-step progress stepper (REQUESTED ➔ ASSIGNED ➔ ACCEPTED ➔ ON_THE_WAY ➔ ARRIVED ➔ COLLECTED ➔ COMPLETED) paired with Leaflet.js. The collector vehicle smoothly animates along the street grid towards the citizen's doorstep while updating the live arrival ETA countdown.
C. Environmental Footprint & Eco Points Economy
• Carbon Offset: Every 1 kg of e-waste recycled prevents 1.44 kg of CO₂ equivalent emissions.
• Tree Absorption Equivalent: Benchmark of 22 kg CO₂ annual absorption per native urban tree.
• Landfill Protection: 0.08 kg of hazardous heavy metals diverted per kilogram processed.
• Rewards Catalog: Citizens redeem points for transit passes, organic grocery vouchers, and native tree planting certificates.
D. AI E-Waste Image Classification (EcoVision Model Prototype)
Users can drag-and-drop or select an image of their item. The neural vision inference simulation identifies the hardware category, surface wear, and potential hazardous components (e.g. Lithium-Ion, Mercury CCFL), automatically populating form fields.
